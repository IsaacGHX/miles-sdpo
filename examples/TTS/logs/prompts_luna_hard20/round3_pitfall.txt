Do not use the ground truth to invent, localize, or repair an error that the attempt does not show.

Output ONLY 1–3 blocks in exactly this format, with no introduction or text outside the blocks:

[Error]

[Rule]
<State a general, operational repair. [Example]

Hard constraints:

- Output only the blocks; never include a repaired solution, final answer, answer choice, requested quantity, count, parameter, constant, or answer-determining intermediate value.

Good:
[Error]
The argument varies a term of one fixed sequence as though it could be changed independently, so it does not address whether one bound works for the stated quantifiers.
[Rule]
Rewrite the quantifiers before varying any value. For a uniform claim, construct a family of admissible objects with values exceeding every proposed bound; for a claim about one fixed object, keep that object fixed and prove unboundedness within it.
[Example]
A bound that may depend on a chosen function is different from a bound required for every function in a class: changing the function for each larger test value disproves only the uniform version, not the fixed-function version.
